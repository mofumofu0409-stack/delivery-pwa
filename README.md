# 定期配達サポート v0.2 PWA

ダスキンのような定期交換・回収型配達を想定した、iPhone中心の試作PWAです。
**この版に入っている顧客情報はすべて架空データです。**

## できること

- 今日の配達一覧
- 地区＋顧客フルネーム表示
- 配達品・数量確認
- 回収数量記録
- 追加／変更フラグ・メモ
- 不在／完了
- 完了後に次の未配達顧客へ自動移動
- Google Mapsへ目的地を渡してナビ
- 最後の未配達／不在／回収差／追加変更チェック
- 進捗を端末ブラウザ内に保存
- PWAホーム画面起動
- 静的ファイルのオフラインキャッシュ

## iPhoneで使うには

PWAの本領を使うにはHTTPSで公開します。無料公開用の手順とCodex用プロンプトは `DEPLOY_GITHUB_PAGES.md` に入っています。

公開後：

1. iPhone SafariでURLを開く
2. 共有 → ホーム画面に追加
3. 「配達サポート」アイコンから起動

## セキュリティ

このv0.2はUI検証用です。勤務先の許可と個人情報の取扱ルールを確認するまでは実顧客データを登録しないでください。実運用版では認証、データ暗号化、端末紛失時の失効、権限管理などを別途設計します。
